# MXZ6 recovery — 20 November 2026

Stage A remains shadow-only. User hedge: 0 MIX. No orders, account access or portfolio writes were added.

## Confirmed causes

- GitHub schedule events arrived with long gaps. Before this fix, successful calculations had gaps exceeding an hour (up to 82.5 minutes on 19 November). This is scheduler delay, not a calculation taking an hour.
- MOEX fetches failed on invalid OHLC, including 20 November at 16:38 and 16:45 MSK. The calculation stopped before data commit and Pages deployment. Original responses were not archived, so the exact malformed original candle cannot be recovered.
- The Stage A wall-clock freshness gate was incorrectly applied while replaying missed closed bars. A delayed runner could erase ARMED and skip other setups.
- A 19 November pre-Stage-A run had a data rebase conflict caused by an old checkout. Current workflows explicitly check out current main before processing; successful writes after this fix are verified.
