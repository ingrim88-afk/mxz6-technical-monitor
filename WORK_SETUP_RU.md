# MXZ6 — подключение в ChatGPT Work, без компьютера пользователя

## Цель

Развернуть облачный монитор MXZ6: GitHub Actions по будням раз в 30 минут загружает **задержанные** свечи с MOEX ISS, считает Alligator, подтверждённые фракталы и RSI на 5m/H1/H4, публикует мобильную веб-страницу через GitHub Pages. Work используется только для настройки репозитория и проверки, **не как круглосуточный сервер**.

## Порядок для ChatGPT Work

1. Распаковать приложенный ZIP (все файлы и скрытая `.github/workflows/mxz6.yml` должны сохраниться).
2. Проверить код на безопасность: чтение общедоступных котировок, никаких финансовых счетов или торговых операций. Python-тесты: `python tests.py`.
3. Убедиться, что у пользователя есть GitHub; попросить авторизоваться через безопасный встроенный механизм, **не просить пароли и токены в чат**. Если GitHub недоступен — не создавать аккаунт/репозиторий без согласия.
4. По разрешению пользователя создать **публичный** репозиторий, например `mxz6-technical-monitor`, загрузить файлы из ZIP в корень, включая скрытый `.github/workflows/mxz6.yml`.
5. В Settings → Pages выбрать Source → **GitHub Actions**. Убедиться, что GitHub Actions включены. Проверить разрешения `pages:write` и `id-token:write` в workflow.
6. Запустить `MXZ6 delayed technical dashboard` вручную (`Actions` → workflow → `Run workflow`), дождаться завершения, открыть итоговый URL GitHub Pages с телефона.
7. Если MOEX отвечает ошибкой / свечи пусты / ticker `MXZ6` не найден, **не подменять реальными данными тестовый набор**. Диагностировать адрес ISS, board RFUD, market FORTS, ticker и формат JSON; исправить и повторить тест.
8. Сверить для одной общей закрытой H1 свечи значение линии Jaw, Teeth, Lips и фрактала с Т-Банком (особенно сдвиги и H4 anchor). Только после этого считать значения пригодными для тактики.
9. Сообщить пользователю прямой URL опубликованной страницы и время последней завершённой свечи. Помочь добавить ссылку на домашний экран Android.

## Как это работает

- Плановые запуски Mon–Fri, с 09:07 до 22:37 **МСК** каждые полчаса (UTC cron в файле). `workflow_dispatch` позволяет ручной запуск из браузера.
- Графики **задерживаются на 15+ минут**, код отсекает последние 16 минут дополнительно, GitHub Actions может запускаться позже расписания. Это не real-time и не подходит для быстрой реакции на 5m.
- GitHub Pages в публичном репозитории доступен всем по ссылке, но показывает **только рыночные технические данные**, не портфель и не брокерский счёт. Не размещать персональные сведения и ключи.
- Не обещать автоматические уведомления в ChatGPT: существующие `RU Market Alerts` / `RU Daily Market Brief` **не связаны** с GitHub Pages. Для push-уведомлений позже требуется отдельная безопасная интеграция (например, Telegram-бот через GitHub Secrets); делать только по отдельной просьбе.
- В публичном репозитории GitHub может остановить `schedule` после 60 дней неактивности, и расписание не гарантирует минутную точность.
- Программа и сайт ничего не покупают и не продают, это самостоятельный технический анализ.

## Если Work не может работать с GitHub

Предложить пользователю открыть Work с этим ZIP и подключить GitHub (если доступно), либо с его разрешения выполнить через облачный браузер GitHub. Не утверждать, что развёртывание состоялось без успешно открытой опубликованной страницы.
